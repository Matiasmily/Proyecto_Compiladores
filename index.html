👋 Bienvenido

¿Cómo funciona este compilador?

Compilador de lenguaje especializado para definir y evaluar reglas de crédito. Ahora con tipos extendidos, operadores de rango y explicaciones detalladas.

1
Declara los campos

Cinco tipos disponibles: entero, decimal, texto, booleano, fecha.

CAMPO decimal ingreso_mensual ;
2
Escribe las reglas

Usa PRIORIDAD, el operador ENTRE, y conectores Y / O / NO.

PRIORIDAD 1 : SI score_crediticio ENTRE 600 Y 750 ENTONCES CONDICIONAR ;
3
Evalúa y obtén explicaciones

El simulador no solo dice el resultado — explica por qué, qué condiciones fallaron y qué se puede mejorar.

Estructura del programa

CAMPO [tipo] [nombre] ;
...
[MONTO_MAXIMO : expr ;]
[TASA : SI cond ENTONCES val ;]
[PLAZO : SI cond ENTONCES accion ;]
PRIORIDAD N : SI [cond] ENTONCES [accion] ;
SI [cond] ENTONCES [accion] ;

Tipos de dato

entero Números enteros (ej: 5000)
decimal Números decimales (ej: 5000.50)
texto Cadenas (ej: "bueno")
booleano verdadero / falso
fecha Formato AAAA-MM-DD

Operadores de comparación

>= Mayor o igual   <= Menor o igual
> Mayor que   < Menor que
= Igual a   != Diferente de

Operador de rango

ENTRE Rango inclusivo
SI score ENTRE 600 Y 750 ENTONCES CONDICIONAR ;

Conectores lógicos

Y Ambas condiciones
O Al menos una
NO Negación

Acciones

APROBAR RECHAZAR CONDICIONAR

Ejemplo expandido

CAMPO decimal ingreso_mensual ;
CAMPO entero score_crediticio ;
CAMPO booleano tiene_garantia ;
CAMPO fecha fecha_nacimiento ;

PRIORIDAD 1 : SI score_crediticio >= 750
  Y ingreso_mensual >= 8000.00
  ENTONCES APROBAR ;

PRIORIDAD 2 : SI score_crediticio
  ENTRE 600 Y 749
  ENTONCES CONDICIONAR ;

PRIORIDAD 3 : SI tiene_garantia = falso
  ENTONCES RECHAZAR ;

Directivas financieras

  • MONTO_MAXIMO : ingreso_mensual * 48 ;
  • TASA : SI score >= 700 ENTONCES 8.5 ;
  • PLAZO : SI plazo_meses <= 60 ENTONCES APROBAR ;
