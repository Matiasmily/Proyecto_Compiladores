👋 Bienvenido

¿Cómo funciona este analizador?

Este compilador analiza un lenguaje especializado para definir reglas de evaluación de crédito. Sigue estos 3 pasos:

1
Declara los campos

Define qué datos usarás y de qué tipo son: entero o texto.

CAMPO entero ingreso ;
2
Escribe las reglas

Cada regla evalúa condiciones y define una acción: APROBAR, RECHAZAR o CONDICIONAR.

SI ingreso >= 5000 ENTONCES APROBAR ;
3
Presiona Analizar

El sistema ejecutará las tres fases: léxica, sintáctica y semántica, mostrando resultados en tiempo real.

Estructura del programa

CAMPO [tipo] [nombre] ;
CAMPO [tipo] [nombre] ;
...
SI [condición] ENTONCES [acción] ;
SI [condición] ENTONCES [acción] ;
...

Primero todas las declaraciones, luego todas las reglas.

Tipos de dato

entero Valores numéricos (ej: 5000) texto Cadenas entre comillas (ej: "bueno")

Operadores de comparación

>= Mayor o igual   <= Menor o igual
> Mayor que   < Menor que   = Igual a

Conectores lógicos

Y Ambas condiciones deben cumplirse   O Al menos una debe cumplirse   NO Niega la condición siguiente

Acciones disponibles

APROBAR Aprueba la solicitud   RECHAZAR Rechaza la solicitud   CONDICIONAR Aprobación con condiciones

Ejemplo completo

CAMPO entero ingreso ;
CAMPO entero edad ;
CAMPO texto historial ;

SI ingreso >= 5000
   Y edad >= 21
   ENTONCES APROBAR ;

SI historial = "malo"
   ENTONCES RECHAZAR ;

Reglas importantes

  • Todo campo debe declararse antes de usarse en una regla.
  • Cada sentencia termina con ;
  • Los campos entero solo se comparan con números.
  • Los campos texto solo se comparan con cadenas entre " ".
  • Los nombres de campo no pueden iniciar con un número.
